MODÉLISEUR 3D V4.1.1 NEURAL — COMPOSANTS OPEN SOURCE

1. IS-Net Anime / Anime Segmentation
Projet d'origine : SkyTNT/anime-segmentation
Modèle embarqué : variante ONNX INT8 publiée par onnx-community/anime-seg-ONNX
Taille du modèle embarqué : 44 182 552 octets
Licence du projet et du modèle d'origine : Apache License 2.0

Le réseau est utilisé localement pour détourer les personnages dessinés. La variante INT8 réduit fortement la mémoire et la taille nécessaires sur Android par rapport au modèle FP32 de 176 Mo.

2. Depth Anything V2 Small
Projet : DepthAnything/Depth-Anything-V2
Modèle embarqué : Depth Anything V2 Small FP32
Licence du modèle Small : Apache License 2.0
Copyright : auteurs et contributeurs de Depth Anything V2
Article : Depth Anything V2: A More Capable Foundation Model for Monocular Depth Estimation

Le modèle est utilisé localement pour estimer les cartes de profondeur de face, de dos et de profil après la reconstruction géométrique. Si le téléphone ne peut pas charger ce réseau, la V4.1.1 conserve automatiquement le maillage géométrique lissé.

3. ONNX Runtime Android
Projet : microsoft/onnxruntime
Licence : MIT License
Copyright (c) Microsoft Corporation et contributeurs

ONNX Runtime exécute les réseaux sur Android. IS-Net Anime INT8 utilise le CPU multi-cœurs pour maximiser la compatibilité. Depth Anything V2 peut demander NNAPI quand l'appareil le permet. Les sessions sont chargées l'une après l'autre pour limiter le pic de mémoire.

4. AndroidX
Projets : Android Open Source Project et AndroidX
Licences : Apache License 2.0 selon chaque composant
