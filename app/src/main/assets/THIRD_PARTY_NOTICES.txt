MODÉLISEUR 3D V4.3 — COMPOSANTS ET SERVICES

1. IS-Net Anime / Anime Segmentation
Projet d'origine : SkyTNT/anime-segmentation
Modèle embarqué : variante ONNX FP32 publiée par onnx-community/anime-seg-ONNX
Taille du modèle embarqué : 176 068 431 octets
Licence du projet et du modèle d'origine : Apache License 2.0

Le réseau est utilisé localement pour détourer les personnages dessinés. La
variante FP32 remplace la variante INT8 dont l'opérateur ConvInteger n'était pas
disponible sur certains téléphones Android.

2. Depth Anything V2 Small
Projet : DepthAnything/Depth-Anything-V2
Modèle embarqué : Depth Anything V2 Small FP32
Licence du modèle Small : Apache License 2.0
Copyright : auteurs et contributeurs de Depth Anything V2

Le modèle est utilisé dans le mode de reconstruction locale pour estimer le
relief. Si le téléphone ne peut pas le charger, le maillage géométrique lissé
reste disponible.

3. ONNX Runtime Android
Projet : microsoft/onnxruntime
Licence : MIT License
Copyright (c) Microsoft Corporation et contributeurs

ONNX Runtime exécute les réseaux locaux. IS-Net Anime FP32 utilise le CPU ;
Depth Anything V2 peut demander NNAPI quand l'appareil le permet.

4. Google Filament
Projet : google/filament
Licence : Apache License 2.0
Copyright (c) Google LLC et contributeurs

Filament et gltfio affichent les GLB PBR et décodent notamment la compression
géométrique meshopt dans l'aperçu V4.3.

5. AndroidX
Projets : Android Open Source Project et AndroidX
Licences : Apache License 2.0 selon chaque composant

6. Service Tripo 3D
API : https://developers.tripo3d.ai/

Tripo n'est pas embarqué dans l'APK. En mode haute fidélité, les images choisies
ou les quatre trames extraites d'une vidéo sont envoyées au service par HTTPS.
Le MP4 complet n'est pas envoyé. La clé API appartient à l'utilisateur et n'est
jamais codée dans l'application. Le mode local n'envoie aucune image.

Les textes de licence et les avis fournis par les bibliothèques empaquetées
restent présents dans leurs distributions originales.
